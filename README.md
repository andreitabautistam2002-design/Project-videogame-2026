# Proyecto Académico: Programación para Videojuegos

¡Hola! Mi nombre es **Leonardo García** y soy estudiante del programa del curso **Programación para Videojuegos** en la UNAD.

##  Sobre este repositorio
Este espacio ha sido diseñado con el propósito de organizar, documentar y presentar los avances prácticos correspondientes al curso. Aquí registraré los componentes del código, recursos de aprendizaje y las actividades solicitadas en la guía del trabajo.

## Objetivos
* Implementar el control de versiones mediante Git y GitHub para registrar de manera transparente el progreso del desarrollo.
* Aplicar los conceptos fundamentales de lógica y programación orientada a la creación de videojuegos.
* Estructurar una base sólida para la entrega de los avances del proyecto académico (Versión v1.0).
